# Pendientes

Temas anotados que todavía no se ejecutaron. Al ejecutar uno, se saca de esta lista.

## Tareas

- **Recurrencia automática de tareas.** Hoy, marcar una tarea como "repetitiva" (cada N días/semanas/meses) es solo una etiqueta: la próxima fecha no se genera sola, hay que usar "Avanzar" manualmente cada vez. Pendiente: que al completar una tarea repetitiva (por ejemplo con el check de finalizar) se genere automáticamente la próxima ocurrencia según la periodicidad configurada, sin pasar por "Avanzar".
